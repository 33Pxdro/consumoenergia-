## 📌 Sobre o projeto

Este programa foi desenvolvido como atividade da disciplina **Desenvolvimento de Sistemas I**.
O objetivo é ajudar usuários a estimar quanto um aparelho elétrico consome de energia por mês, 
com base em dados simples de uso, como potência e tempo médio de utilização diária.

## 🎯 Objetivo do sistema

Calcular o consumo mensal de energia (em kWh) de um aparelho elétrico e estimar o custo 
mensal desse consumo, ajudando o usuário a entender melhor seus gastos com energia.

## 🐍 Linguagem utilizada

- **Python 3**

## 🧮 Fórmula utilizada


Onde:
- `potencia` → potência do aparelho em Watts (W)
- `horasDia` → tempo médio de uso diário em horas
- `30` → dias considerados no mês
- Divisão por `1000` → converte de Wh para kWh

O custo estimado é calculado multiplicando o consumo mensal por um valor fixo de **R$ 0,75 por kWh**.

## ▶️ Como executar o programa

1. Certifique-se de ter o Python instalado (ou use um ambiente online como o Replit).
2. Baixe ou clone este repositório.
3. No terminal, execute:

```bash
python app.py
```

4. Informe o nome do aparelho, a potência (em Watts) e o tempo médio de uso diário (em horas).
5. O programa exibirá o consumo estimado em kWh/mês e o custo estimado em reais.
